Was Pflegra ordnet

Alles Wichtige zur Pflege an einem Ort.

Pflegra ersetzt keine Pflegeberatung. Es hilft Ihnen, den organisatorischen Teil der Pflege besser zu bewältigen.

📁
Dokumente organisieren
Bescheide, Gutachten, Arztbriefe und Nachweise gesammelt ablegen und schneller wiederfinden.
📅
Fristen im Blick behalten
Wichtige Termine und Fristen festhalten, bevor etwas untergeht.
🗓️
Termine verwalten
Arzttermine, Pflegeberatung und eigene Termine übersichtlich sammeln.
✅
Aufgaben festhalten
Offene Erledigungen notieren und Schritt für Schritt abhaken.
📋
Gutachten nachvollziehen
Pflegegrad und MD-Gutachten besser verstehen und einordnen.
📞
Kontakte sammeln
Pflegekasse, Ärzte, Pflegedienst und Beratungsstellen griffbereit halten.

Pflegra kann noch mehr. Für den ersten Überblick reicht aber genau das: Ordnung, Erinnerung und schnelleres Wiederfinden.

Warum Pflegra?

Pflegra entstand nicht in einer Firma. Sondern in einer Pflegesituation.

Am Anfang reichten Ordner, Zettel und Tabellen. Dann wurden es mehr Schreiben, mehr Fristen, mehr Fragen und mehr Dinge, die man nicht vergessen durfte.

Pflegra ist aus diesem Alltag entstanden. Nicht, weil jemand eine Software verkaufen wollte. Sondern weil eine Familie selbst eine Lösung brauchte, um den Überblick zu behalten.

Heute soll Pflegra anderen Angehörigen genau dabei helfen.

Datenschutz

Pflegedaten sind persönlich. Sie sollen es bleiben.

In Pflegedokumenten stehen sehr private Informationen: Diagnosen, Gutachten, Bescheide, Kontakte und persönliche Notizen. Deshalb soll jeder selbst entscheiden können, wo diese Daten gespeichert werden.

🔒
Keine Werbung Pflegra ist kein Werbeprodukt und verkauft keine Aufmerksamkeit.
📡
Kein Tracking Kein Analytics, keine Verhaltensprofile, keine versteckte Auswertung Ihrer Nutzung.
🤝
Keine Weitergabe Ihrer Daten Pflegedaten sollen unter Ihrer Kontrolle bleiben.
🔍
Für technisch Interessierte transparent Pflegra kann selbst betrieben werden. Der Quellcode ist öffentlich einsehbar.

Für Menschen mit technischer Erfahrung, Docker, Linux oder eigenem Server.

GitHub ansehen
# 1. Pflegra-Paket herunterladen und entpacken # pflegra_windows_v1.6.2.zip → beliebiger Ordner # 2. Pflegra.exe doppelklicken # → Browser öffnet sich automatisch # → Tray-Symbol erscheint in der Taskleiste

Kein Docker nötig. Pflegra läuft direkt als eigenständige Windows-Anwendung. Daten werden lokal gespeichert und bleiben auf Ihrem PC. Download v1.6.2 →

# Einzeiler docker run -d -p 8000:8000 -v pflegra_data:/data ghcr.io/pflegra/core:latest # Oder mit docker compose git clone https://github.com/Pflegra/core.git cd core docker compose up -d

Pflegra läuft dann unter http://localhost:8000

# Docker installieren curl -fsSL https://get.docker.com | sudo sh # Pflegra starten mkdir -p ~/pflegra/data docker run -d -p 8000:8000 \ -v ~/pflegra/data:/data \ --name pflegra \ --restart unless-stopped \ ghcr.io/pflegra/core:latest

Pflegra läuft unter http://SERVER-IP:8000
Für Fernzugriff: Tailscale installieren und Funnel aktivieren.
