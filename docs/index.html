Warum Pflegra?

Wir sind keine Softwarefirma. Wir sind eine Familie, die selbst pflegt.

Wie viele andere Familien haben wir irgendwann festgestellt, dass die Pflege nicht die größte Herausforderung ist. Die größte Herausforderung ist oft alles, was drum herum passiert.

Anträge ausfüllen. Fristen einhalten. Schreiben der Pflegekasse abheften. Arzttermine organisieren. Nachweise aufbewahren. Ansprechpartner finden. Dokumente wiederfinden, wenn sie Monate später plötzlich gebraucht werden.

Jeder einzelne Punkt für sich ist nicht schlimm. Aber mit der Zeit wird daraus ein Berg an Aufgaben.

Wir kennen Abende, an denen man eigentlich nur noch auf die Couch möchte, und stattdessen versucht herauszufinden, wann die letzte Pflegeberatung war oder in welchem Ordner ein bestimmtes Schreiben liegt. Wir kennen das Gefühl, ständig Angst zu haben, etwas Wichtiges zu vergessen.

Genau daraus ist Pflegra entstanden. Nicht, weil wir eine App entwickeln wollten. Sondern weil wir selbst Entlastung gebraucht haben.

Die Pflege können wir nicht übernehmen. Den Papierkram vielleicht schon.

Wenn Sie heute mit Ordnern, Zetteln oder Tabellen gut zurechtkommen, ist das völlig in Ordnung. Wir haben lange genau das Gleiche gemacht.

Die meisten Familien beginnen mit einem Ordner. Wir auch. Pflegra entstand erst, als der Ordner nicht mehr gereicht hat.

Pflegra ist für den Moment entstanden, in dem man merkt, dass man nicht mehr alles alleine im Kopf tragen kann.

Pflegra begann nicht als Softwareprojekt. Es begann mit einer einfachen Tabelle für die Verhinderungspflege. Aus dieser Tabelle wurden Makros. Aus Makros wurde PflegeNachweis. Aus PflegeNachweis wurde Pflegra.

Datenschutz

Ihre Daten gehören Ihnen.

Pflegra wurde von Grund auf nach dem Prinzip „Daten bleiben lokal" entwickelt.

🔒
Keine Cloud, kein Server Alle Daten liegen in einer SQLite-Datenbank auf Ihrem eigenen System.
📡
Keine Telemetrie Kein Analytics, kein Tracking, keine Übertragung an externe Server.
🔍
Quellcode offen Jede Zeile Code ist auf GitHub einsehbar. AGPLv3 lizenziert.
💾
Automatische Backups Tägliche automatische Backups mit integrierter Wiederherstellung, Ihre Daten sind auch bei Serverproblemen sicher.
Installation

In 3 Schritten starten

Pflegra läuft auf Linux Server, Docker Desktop (Windows/Mac/Linux) oder direkt per Python.

# 1. Pflegra-Paket herunterladen und entpacken # pflegra_windows_v1.5.6.zip → beliebiger Ordner # 2. Pflegra.exe doppelklicken # → Browser öffnet sich automatisch # → Tray-Symbol erscheint in der Taskleiste

Kein Docker, keine Installation nötig. Pflegra läuft direkt als eigenständige Windows-Anwendung. Daten werden lokal gespeichert und bleiben auf Ihrem PC. Download →

# Einzeiler docker run -d -p 8000:8000 -v pflegra_data:/data ghcr.io/pflegra/core:latest # Oder mit docker compose git clone https://github.com/Pflegra/core.git cd core docker compose up -d

Pflegra läuft dann unter http://localhost:8000

# Docker installieren curl -fsSL https://get.docker.com | sudo sh # Pflegra starten mkdir -p ~/pflegra/data docker run -d -p 8000:8000 \ -v ~/pflegra/data:/data \ --name pflegra \ --restart unless-stopped \ ghcr.io/pflegra/core:latest

Pflegra läuft unter http://SERVER-IP:8000
Für Fernzugriff: Tailscale installieren und Funnel aktivieren.
