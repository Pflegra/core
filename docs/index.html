Datenschutz

Ihre Daten gehören Ihnen.

Pflegra wurde von Grund auf nach dem Prinzip „Daten bleiben lokal" entwickelt.

🔒
Keine Cloud, kein Server Alle Daten liegen in einer SQLite-Datenbank auf Ihrem eigenen System.
📡
Keine Telemetrie Kein Analytics, kein Tracking, keine Übertragung an externe Server.
🔍
Quellcode offen Jede Zeile Code ist auf GitHub einsehbar. AGPLv3 lizenziert.
💾
Automatische Backups Tägliche lokale Backups mit konfigurierbarer Aufbewahrungszeit.
Installation

In 3 Schritten starten

Pflegra läuft auf Docker Desktop (Windows/Mac/Linux), Linux-Server oder direkt per Python.

# 1. Docker Desktop installieren (einmalig) # https://www.docker.com/products/docker-desktop # 2. Windows-Paket herunterladen und entpacken # pflegra_windows_vXX.zip → beliebiger Ordner # 3. start.bat doppelklicken → Browser öffnet sich

Docker Desktop muss installiert und gestartet sein. Beim ersten Start wird das Image automatisch heruntergeladen (~200 MB). Download →

# Einzeiler docker run -d -p 8000:8000 -v pflegra_data:/share/pflegra ghcr.io/pflegra/core:latest # Oder mit docker compose git clone https://github.com/Pflegra/core.git cd core docker compose up -d

Pflegra läuft dann unter http://localhost:8000

# Docker installieren curl -fsSL https://get.docker.com | sudo sh # Pflegra starten mkdir -p ~/pflegra/data docker run -d -p 8000:8000 \ -v ~/pflegra/data:/share/pflegra \ --name pflegra \ --restart unless-stopped \ ghcr.io/pflegra/core:latest

Pflegra läuft unter http://SERVER-IP:8000
Für Fernzugriff: Tailscale installieren und Funnel aktivieren.
